    Wave Mode¶

    Wave Mode Forest and Sky Instances Officially monsters can use their skills (NPC_SUMMONSLAVE, at least). NPC_EMOTION and NPC_EMOTION_ON have been blocked since it disrupts the walk system of the instance on rAthena. Note: The instance is currently disabled on KRO.

    Overview¶

    • Entrance: Zonda Rep at prontera 146/75 (/navi prontera 146/75)
    • Requirements (Wave Mode - Forest): Unlocked by its story quest, time limit 1h, no cooldown
    • Requirements (Wave Mode - Sky): Unlocked by its story quest, time limit 1h, no cooldown
    • Who can enter: Party (create a party first)
    • Modes: Wave Mode - Forest, Wave Mode - Sky
