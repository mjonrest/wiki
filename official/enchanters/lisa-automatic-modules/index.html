    Lisa (Automatic Equipment Modules)¶

    In the Database

    Every item this enchanter works on, the enchants it adds and the NPC on the map: open its Database entry. Item pages link back here too.

    Lisa, inside Varmundt's mansion (Episode 17.2), installs Automatic Modification Modules into the Automatic equipment set. You choose the module yourself, so every enchant is guaranteed. The NPCs next to her sell the modules and turn Illusion equipment into Automatic equipment.

    Where: /navi ba_in01 87/370

    Menu Equipment slot Items

    Automatic Armor Enhancement Armor Automatic Armor Type A [1] #450127, Automatic Armor Type B [1] #450128
    Automatic Leg Enhancement Shoes Automatic Leg Type A [1] #470022, Automatic Leg Type B [1] #470023

    Automatic Accessories(L) Enhancement Left accessory Automatic Booster L [1] #490025, Automatic Battle Chip L [1] #490027

    The item must be equipped in that slot and you need room in your inventory. There is no refine requirement.

    Enchanting¶

    1. Pick the equipment menu, then the module grade (Normal, Rare, Unique, Legendary, Epic Grade 1, Epic Grade 2 or Epic Grade 3).
    2. Pick the module. Modules you do not have show as "(Module Amount 0)".

    3. Confirm. Lisa warns that it cannot be reversed.

    4. Cost: 1 module of the chosen type. No zeny.

    5. Success: always succeeds. Refine and cards are kept and the item is never destroyed.
    6. Slots: each item takes up to 3 modules, filling the 4th, 3rd and then 2nd slot. Once the 2nd slot is used the item is "at its maximum capacity".
    7. Each module type has its own limit per item (last column). A module that is not in the item's table is refused ("You can not enchant this module to this automatic equipment").
    8. There is no reset.

    Yeoncheong: Illusion to Automatic exchange¶

    /navi ba_in01 87/383

    Tip

    Yeoncheong warns that if you carry more than one copy of the required Illusion item, the one used is picked at random. Carry only the copy you want to trade.
