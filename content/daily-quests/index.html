    Daily Quests¶

    Location: prontera 154, 198

    Register once a day and complete 5 quests, one after another. Each finished quest gives a random reward and a server announcement. Only one account per computer can register each day.

    Quest types¶

    Each quest is a random type and a random difficulty:

    Difficulty Hunting Collecting Instance
    Easy Kill 100 Bring 200 Clear any 5 instances
    Medium Kill 200 Bring 5 Clear any 5 instances
    Hard Kill 300 Bring 1 Clear any 5 instances
    • Hunting asks for one monster from the hunting list below.
    • Collecting asks for one item from the list for that difficulty. The items are taken when you submit.
    • Instance counts any instance you clear (party instances count for the whole party).
