    Accessory Enchanter (Aulion)¶

    In the Database

    Every item this enchanter works on, the enchants it adds and the NPC on the map: open its Database entry. Item pages link back here too.

    Location: moc_para01 42, 38 · Quest Room
    Enchant cost 2× Enchant Ticket #1000874 + 10,000,000 Zeny
    Reset cost 5× Enchant Ticket #1000874 + 5,000,000 Zeny

    Each enchant fills the next empty slot (slot 2, then 3, then 4) with one random enchant from that slot's pool. Every enchant in a pool has the same chance. Reset clears slots 2 to 4 so you can start again.
