# Temporal Circlet Enchanter

<!-- npcs: OSC0005; HUGINN2001 -->

## Enchant steps

The enchants go in order: 1st → 2nd → 3rd. Each step needs the previous one and an empty target slot.
Every step always succeeds. Refine and cards are kept. The enchant grade and random options are not kept.

## Level Up Special Enchant

The seven Lv. 1 "special" enchants from the Third Enchant (Tenacity, Mettle, Affection, Adamantine,
Master Archer, Magic Essence, Acute) can be raised up to **Lv. 10**. The Sharp, Expert Archer, attack delay and
Spell results cannot be leveled.

Each try costs {{ item(25866) }} and has a **60%** success chance. On failure the enchant **drops one level**
(a Lv. 1 enchant stays Lv. 1). The Spells are used up either way.

| Upgrade | Temporal Spells |
|---|---|
| Lv1 → Lv2 | 4 |
| Lv2 → Lv3 | 6 |
| Lv3 → Lv4 | 8 |
| Lv4 → Lv5 | 10 |
| Lv5 → Lv6 | 12 |
| Lv6 → Lv7 | 16 |
| Lv7 → Lv8 | 20 |
| Lv8 → Lv9 | 28 |
| Lv9 → Lv10 | 40 |

For example {{ item(29706) }} goes up to {{ item(29715) }} and {{ item(29061) }} up to {{ item(29070) }}.

## Reset Enchants

| Option | Success | On failure |
|---|---|---|
| 500,000z | 70% | **The circlet is destroyed** |
| 10 Cash Points | 100% | - |

The reset keeps the refine and the card in the first slot. If the circlet has no enchants, she refuses before taking any cost. A failed 500,000z reset still destroys the circlet.
