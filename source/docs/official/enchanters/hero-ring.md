# Hero Ring Enchanter (Morocc)

<!-- npcs: Expert Enchanter Byrnes; Hero Token Exchanger -->

**Expert Enchanter Byrnes** enchants all four slots of the Hero Ring ({{ item(2981) }}). The
**Hero Token Exchanger** next to him trades {{ item(6684) }} for the ring.

**Where:** Byrnes `/navi moro_cav 34/65`, Hero Token Exchanger `/navi moro_cav 32/73`

## Getting the ring

Trade **30 {{ item(6684) }}** at the Hero Token Exchanger for one {{ item(2981) }}.

## Enchanting

Wear the ring and tell Byrnes whether it is on the **left** or **right**. Each enchant is **free** and always
succeeds. Each time you choose the type for the next slot, and the level is random (20% each).

The slots fill in this order: slot 4 → slot 3 → slot 2 → slot 1. Once slot 1 has an enchant the ring is
finished.

## Reset

**Cost:** 3 {{ item(6684) }}. Always succeeds and gives back a clean ring with no enchants. The ring must be
worn and have at least one enchant.

!!! tip
    Enchanting is free, so the only cost of chasing a perfect ring is 3 Hero Tokens per reset.
