# Lisa (Automatic Equipment Modules)

<!-- npcs: Lisa; Yecheon; Yeoncheong; Spiera -->

Lisa, inside Varmundt's mansion (Episode 17.2), installs **Automatic Modification Modules** into the
Automatic equipment set. You choose the module yourself, so every enchant is guaranteed. The NPCs next to her
sell the modules and turn Illusion equipment into Automatic equipment.

**Where:** `/navi ba_in01 87/370`

## Enchanting

1. Pick the equipment menu, then the module grade (**Normal**, **Rare**, **Unique**, **Legendary**,
   **Epic Grade 1**, **Epic Grade 2** or **Epic Grade 3**).
2. Pick the module. Modules you do not have show as "(Module Amount 0)".
3. Confirm. Lisa warns that it cannot be reversed.

- **Cost:** 1 module of the chosen type. No zeny.
- **Success:** always succeeds. Refine and cards are kept and the item is never destroyed.
- **Slots:** each item takes up to **3 modules**, filling the 4th, 3rd and then 2nd slot. Once the 2nd slot is
  used the item is "at its maximum capacity".
- Each module type has its own limit per item (last column). A module that is not in the item's table is
  refused ("You can not enchant this module to this automatic equipment").
- There is **no reset**.
