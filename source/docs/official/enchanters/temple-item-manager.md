# Temple Item Manager (Bishop Necklace)

<!-- npcs: Temple Item Manager -->

The Temple Item Manager in Rachel puts a "Goddess" enchant on the {{ item(28387) }} from the *Half Moon in the
Daylight* content, using {{ item(25088) }}.

**Where:** `/navi rachel 177/139`

## Items it works on

Only {{ item(28387) }}. It must be **equipped** in the accessory slot you pick (left or right). You need at least
1,000 free weight.

## Enchanting

Talk to him, pick **"Well then, please."**, choose **Left** or **Right**, then pick a Goddess power and a class.
You choose the exact enchant, so there is no random roll and it never fails. The enchant goes into the 4th slot.

| Power | A Class (100 {{ item(25088) }}) | S Class (1,000 {{ item(25088) }}) |
|---|---|---|
| Goddess of Justice | {{ item(29121) }} | {{ item(29122) }} |
| Goddess of Mercy | {{ item(29123) }} | {{ item(29124) }} |
| Goddess of Insight | {{ item(29125) }} | {{ item(29126) }} |

- **A Class:** costs 100 {{ item(25088) }}. The necklace must not have an enchant yet.
- **S Class:** costs 1,000 {{ item(25088) }}. The NPC says the necklace must already carry the A Class of the same
  power (for example {{ item(29121) }} before {{ item(29122) }}).
- No zeny is needed. The necklace is replaced by a new one carrying the chosen enchant.

There is no reset option at this NPC.

!!! warning "Known issue"
    The S Class enchants cannot be obtained. Before you even reach the class menu, the NPC refuses any necklace
    that already has an enchant ("This necklace of yours already has an enchantment."). But the S Class upgrade
    needs the A Class enchant to be on the necklace already, so the S Class choice is never reachable with a
    valid necklace. Choosing S Class on a clean necklace only gives "You need to have your necklace enchanted with
    ... first." Do not farm 1,000 Fragments for it.
