# Horror Toy Factory Enchanter

<!-- npcs: Black Beard Joe; Vagrant Cain -->

In Lutie, **Black Beard Joe** enchants the Horror Toy Factory gear for {{ item(7642) }}. Next to him,
**Vagrant Cain** turns some of that gear into stronger items.

**Where:** Black Beard Joe `/navi xmas 240/294`, Vagrant Cain `/navi xmas 240/297`

Both need at least 10,000 free weight.

## Black Beard Joe

Every try costs **15 {{ item(7642) }}**. Wear the item, then pick the menu for its slot.

| Menu | Items (must be worn in that slot) | Max enchants | Can break? |
|---|---|---|---|
| Enchant accessory | {{ item(2976) }}, {{ item(2977) }}, {{ item(2978) }}, {{ item(2980) }} (**right** accessory slot only) | 3 | Yes |
| Enchant weapon | {{ item(13442) }} | 1 | No |
| Enchant headgear | {{ item(18848) }}, {{ item(18849) }} | 2 | No |
| Enchant footwear | {{ item(2486) }} | 2 | No |

Refine and cards are kept. Enchants fill slot 4 first, then slot 3, then (accessories only) slot 2.
{{ item(16029) }} is enchanted by Mayomayo in Malangdo instead.

### Accessories

Pick one of two stat groups each time:

- **STR/AGI/DEX**
- **INT/VIT/DEX**

Each try can fail, and a failure **destroys the accessory**. The chances get worse with each enchant:

| Enchant | Breaks | +1 (each stat) | +2 (each stat) | +3 (each stat) | +4 (each stat) |
|---|---|---|---|---|---|
| 1st (slot 4) | 10.18% | 19.96% | 9.98% | - | - |
| 2nd (slot 3) | 22.34% | 14.79% | 7.4% | 3.7% | - |
| 3rd (slot 2) | 51.68% | 8.61% | 4.31% | 2.15% | 1.03% |

"Each stat" means each of the three stats in the group you picked. For example, picking STR/AGI/DEX on the
1st enchant gives {{ item(4700) }}, {{ item(4730) }} or {{ item(4720) }} at 19.96% each and
{{ item(4701) }}, {{ item(4731) }} or {{ item(4721) }} at 9.98% each.

## Vagrant Cain

Trades Toy Factory gear plus coins for a better item. The new item is brand new: refine, enchants and cards of
the old one are lost.

| You get | You need |
|---|---|
| {{ item(18849) }} | Wear {{ item(18848) }} refined to **+9 or higher** + 1,000 {{ item(7642) }} |
| {{ item(16029) }} | Wear {{ item(1540) }} in your right hand + 2,000 {{ item(7642) }} |
| {{ item(2980) }} | 1 {{ item(2977) }}, 1 {{ item(2978) }}, 1 {{ item(2976) }} + 1,000 {{ item(7642) }} |

For Evil Spirit Gloves the three accessories are taken from your inventory. If you own more than one of the
same accessory, you cannot choose which copy is used.
