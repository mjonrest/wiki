# RS26 (Illusion Armor Modules)

<!-- npcs: RS26 -->

RS26 is a hologram robot in the Episode 17.1 Rebellion base that installs **Modification Modules** into the
Illusion armor set that Elyumina makes. You pick the module yourself, so every enchant is guaranteed.

**Where:** `/navi sp_cor 106/136`

The item must be **equipped** in that slot. You need 1,000 free weight and room in your inventory. There is no
refine requirement.

## Enchanting

1. Pick the equipment menu, then the module grade (**Normal**, **Rare**, **Unique** or **Legendary**).
2. Pick the module from the list. Modules you do not have are greyed out.
3. RS26 shows how many of that module are already on the item and asks you to confirm.

- **Cost:** 1 module of the chosen type. No zeny.
- **Success:** always succeeds. Refine and cards are kept and the item is never destroyed.
- **Slots:** each item takes up to **3 modules**. They fill the 2nd, 3rd and 4th slots in that order. Once the
  4th slot is used the item is at its limit.
- Each module type has its own limit per item (last column below).
- A module that is not in the item's table is refused ("You need to have a module that matches the efficacy").
