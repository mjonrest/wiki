# Official Instances

Miracle loads **{{ official_instance_count() }}** official memorial dungeons, sorted by level. Clearing the supported ones also gives
[Instance Points](../../content/instances.md).

- **Level** is the minimum base level the entrance NPC checks. **—** means it checks quest progress instead,
  so finish that instance's story quest first.
- **Time limit** is how long the instance stays open once created.
- **Cooldown** is how long you wait before entering again. **—** means the script sets none.
- Type `/navi <map> <x>/<y>` in game to get an arrow to the entrance.
