# Database

Look up any item, monster, skill, NPC, enchant or job on Miracle. Everything here is read from the server's own databases when
the wiki is built, including Miracle's custom items, monsters and jobs, so it matches the game.

<div class="grid cards" markdown>

-   :material-sword: **[Items](items.md)**

    Stats, effects, equip jobs, which monsters drop it, which NPCs sell it and which boxes contain it.

-   :material-ghost: **[Monsters](monsters.md)**

    Stats, element, race and size, drops with their chance on this server, and the maps they spawn on.

-   :material-book-open-variant: **[Skills](skills.md)**

    SP cost, cast time, cooldown and range per level, and which jobs learn it.

-   :material-storefront: **[NPCs](npcs.md)**

    Where every NPC stands, what it sells or trades, which items it gives or takes, its menu and its quests.

-   :material-auto-fix: **[Enchants](enchants.md)**

    Enchant systems opened by NPCs and Laphine synthesis and upgrades: costs, enchant chances and rewards.

-   :material-account-group: **[Jobs](jobs.md)**

    Skill trees with prerequisites, job bonus stats, HP and SP, and base ASPD per weapon.

</div>

!!! note "About drop chances"
    Chances already include the server's drop rates from `conf/battle/drops.conf`, the same way the server
    applies them, and are capped at 100%. Item effects are shown as the server script, so some lines may read
    like code.
