# Instance Points

Every instance on Miracle that gives **Instance Points**, how many, and how often you can earn them.
Points are spent at the [Instance Point Merchant](../shops/instance-point-merchant.md).
See [Instances](instances.md) for the basics.

| | |
|---|---|
| **Daily cap** | 1,200 points per account, reset at 00:00 server time |
| **Limit** | Each computer can claim each instance run once |
| **Bonus** | +50 points per claim while {{ item(30034) }} is active |
| **Check** | `@instancepoints` shows how many points you earned today |

- **Points** are a random amount in the range shown, given when you leave or claim the reward at the end.
  Harder modes and higher levels give more.
- **Cooldown** is how often you can run the instance. **Daily** means the lockout ends at the next 04:00 server
  time. **Story, once** means the instance is part of a story quest and is only done once per character.
- The tables are grouped by episode and sorted by points, highest first.
