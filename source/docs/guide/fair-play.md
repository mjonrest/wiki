# Anti-bot & Fair Play

## Gepard Shield

Miracle runs **Gepard Shield** anti-cheat. Gepard identifies each computer, and several rewards are limited
**per computer** rather than per account:

- [Freebies](new-players.md#1-claim-your-freebies) (once per computer)
- [Daily Quest](../content/daily-quests.md) registration (one per computer and IP per day)
- [Instance Points](../content/instances.md) (one claim per computer per instance run)
- [Activity Points](../content/gacha.md) (one character per computer)

## One character per computer

These maps allow only one character per computer. A second one is warped back to Prontera:

- The [World Boss](../content/world-boss.md) map
- [Hell Raid](../content/hell-raid.md) (`ordeal_3-1`) and the Battle Rumble arena
- PvP rooms and the `guild_vs` arenas

## Captcha (macro checker)

GMs can run a **captcha check** on any map. Everyone there gets an image with a 6-character code and must
type it back within **60 seconds**. You get **6 tries**. Running out of time or tries **bans the account**, so
answer it even if you are busy.
