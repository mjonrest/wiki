# Skill Changes

Skills on Miracle work like official kRO, with the changes below. The [Skills database](../db/skills.md) shows each
changed skill with a **Miracle change** note.

| Skill | Class | Change |
|---|---|---|
| [Mayhemic Thorns](../db/skills.md#BO_MAYHEMIC_THORNS) | Biolo | Hits **4 times** while [Research Report](../db/skills.md#BO_RESEARCHREPORT) is active, and 3 times without it. |
